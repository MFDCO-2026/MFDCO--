# MFDCO Country Operations v10

## 国家資料 / Wikipedia風情報
- 国の標語
- 国民・住民呼称
- 公用文字
- 最大都市
- 国際電話番号
- 国別トップレベルドメイン
- 車両通行方向
- 日付表記
- 国番号・識別番号
- 民族・住民集団

## 税制
- 税制概要
- 税目を無制限追加
- 税分類 / 標準税率 / 課税対象 / 備考

## 社会指標 / 社会問題
- 国民幸福度
- 幸福度順位
- 民主主義指数
- 報道の自由順位
- 汚職指数
- 平等指数
- HDI
- 社会問題専用データ（分類 / 深刻度 / 概要）

## 資源・エネルギー
- 食料自給率3方式を継続
- エネルギー源ごとの構成比
- エネルギー源ごとの自給率
- 任意資源自給率との併用

## 気候
- 12か月の平均気温
- 12か月の降水量
- 国家ページで雨温図を自動描画
- 資料図表ページに「雨温図」テンプレート / 自動生成を追加

## 軍事
- 予備役
- 準軍事組織
- 徴兵制度概要
- 核弾頭数
- 最高司令部 / 大本営
- 保有戦力を兵器分類から選択可能
- 正式採用兵器の種類を戦車・軍艦・航空機等に標準化
- 正式採用兵器ページを分類ごとのセクション表示へ変更
- 正式採用兵器に予備状態を追加
- 配備部隊をDBに保存する unit_name を追加

## 外交
- 国家ページ上に同盟・条約・外交関係を表示
- 本番Supabase接続時は相手国名を取得して国家ページへリンク
- 関係状態 / 開始日 / 条件を表示

## リアルタイム時刻
- UTC/GMT差から国家現地時刻を1秒ごとに表示
- 標準時名称と併記

## レイアウト
- ヒーロー高さを圧縮
- 国家Wikiのセクション間余白を縮小
- 目次の文字サイズ・行高を圧縮
- デスクトップでは目次を原則1画面に収まりやすく調整
- モバイルでは目次を2列化

## 大永都帝國
- PDF資料の順位から幸福度58位、報道の自由145位、民主主義指数68位、汚職指数24位、平等指数161位を反映
- 社会問題6件を専用データへ反映
- 核弾頭400発を軍事情報へ反映
- 資料にない税制・月別気候値等は未設定のまま維持
