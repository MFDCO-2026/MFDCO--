# MFDCO Country v17.3

## 歴史
- 時代分類を「大分類 → 小分類 → 元号 → 歴史イベント」の4段階へ拡張。
- 既存の `eras` は初回表示時に大分類候補へ移行。
- 既存の元号形式の `chronology.calendars` は元号候補として取り込み可能。
- イベントから大分類 / 小分類 / 元号を選択可能。
- 元号開始年とイベント年から「元年 / 2年 ...」を自動表示。
- 建国紀元など元号とは別の紀年法は「その他の紀年法」として維持。

## 正式採用
- 承認済みMFDCO Workを取得する専用RPC `mfdco_public_works_for_adoption` を追加。
- Works側RLSの違いで一覧が空になる問題を回避。
- 取得エラーを画面に表示し、再取得ボタンを追加。
- 最大500作品を読み込み、作品名 / 説明 / タグ / 提出方式で検索。

## 世界経済
- 月次・日次の値動き要因を廃止。
- 全市場値を1時間単位で更新。
- 通常の1時間変動幅を小さくし、旧日次設定から自動移行。
- 強材料・弱材料・資源材料は決定論的な不規則時刻（概ね1〜11時間間隔）で切替。
- 閲覧者がいなくても時刻から同一履歴を再現。
- ログイン時に過去履歴をDBへ補完し、旧モデルの同時刻行もv17.3値へ更新可能。
- 株価指数・FX・世界総合をOHLC風に表示。
- 主要企業の株価、1時間変動、始値・高値・安値を表示。
- 「企業株価平均」を追加。国家ごとに名称を設定可能（例: MFDCO30平均）。
- 168時間チャートは世界総合 / 国家指数 / 企業平均を同一0%基準で比較。

## 交通
- 高速道路網を個別路線として登録可能。
- 鉄道路線を個別登録可能。
- 在来線 / 高速鉄道 / 地下鉄 / 貨物鉄道 / モノレール等を分類可能。
- 公開国家ページにも高速道路網・鉄道路線を表示。

## 編集UI
- 「＋追加」等で右側を再描画しても、開いていた詳細カードを維持する処理を強化。

## DB
- `country_records` に以下の record_type を追加利用（テーブル変更不要）:
  - `history_major_period`
  - `history_minor_period`
  - `regnal_era`
  - `highway`
  - `railway`
- 新規RPCのみSQL追加が必要。
