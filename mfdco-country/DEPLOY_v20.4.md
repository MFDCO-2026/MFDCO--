# Deploy v20.4

1. MFDCO本体の `https://mfdco.net/js/supabase-config.js` は現在ホームページで使用中の本物をそのまま維持してください。
2. Country v20.4のWebファイルを配置してください。Countryパッケージには `js/supabase-config.js` を含めません。
3. Country DBを0から作る場合は `MFDCO_country_supabase_FRESH_COMPLETE_v22.sql` を全文実行します。
4. SQL Editorでは一部を選択せず、ファイル全文を貼り付けてRunしてください。
5. ホームでログイン → 国家運営へ移動 → 右上に同じ活動名が出ることを確認してください。
