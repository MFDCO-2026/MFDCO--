# MFDCO Country v20.8

## Login-state hang fix
- 国家一覧の初期描画をログイン確認から分離。
- 公開国家一覧取得では `user()` / `getSession()` を待たない。
- 「ログイン状態を確認中...」を恒久表示しない。
- 認証取得にはタイムアウトを設定。
  - Supabase client待機: 2.5秒
  - getSession: 3秒
  - profile取得: 3秒
- 認証取得失敗時は必ず「ログインして国家を作成」へフォールバック。
- バックグラウンドで再確認し、ログインが取れれば「＋ 国家を作成」へ自動更新。
- `getState(true)` が古いinitPromiseを返していた問題を修正し、本当に再取得するよう変更。
- Headerの編集権限判定も同じ認証ブリッジを使用。

DB変更はありません。v23.6のままで使用できます。
