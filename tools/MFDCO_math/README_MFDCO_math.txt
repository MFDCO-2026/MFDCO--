MFDCO_math
==========

公開版 1.0.0
内部開発系統: MFDCO Tools v3.8.2

概要
----
MFDCO_math はブラウザで動作する科学計算・工学計算・記号計算ツールです。
サーバー側実行を必要とせず、静的Webサイトとして配布できます。

主な機能
--------
- 関数電卓
- コード実行
- 変数 / ANS
- DEG / RAD
- 単位付き計算
- 次元解析
- 153単位の変換
- グラフ描画
- 零点 / 極値 / 交点 / 接線 / 面積
- PNG / CSV / SVG出力
- ベクトル / 行列
- 記号計算
- 多項式展開 / 因数分解
- 記号微分 / 記号積分
- Taylor / Maclaurin
- 複素数
- 方程式 / 連立方程式
- 統計 / 回帰
- 確率分布
- 力学 / 流体 / 材料 / 熱 / 電気 / 天体計算
- 大規模コードテンプレート
- プロジェクト保存 / 読み込み
- Undo / Redo
- 自動保存 / バックアップ
- 同一ブラウザ内のタブ同期

起動方法
--------
index.html または calculator.html をブラウザで開いてください。

静的ホスティング
----------------
GitHub Pages、Cloudflare Pages、Netlify、通常のWebサーバー等で配置できます。
PHP / Node.js / データベースは必須ではありません。

複数利用者
----------
別PC・別ブラウザプロファイルの利用者同士で計算内容は共有されません。
同じブラウザプロファイルで同一サイトを複数タブ開いた場合のみ、
BroadcastChannel によりワークスペースが同期されます。

ホームページとの接続
--------------------
全ページ共通ヘッダーに「MFDCOのツール一覧を見る」ボタンがあります。

標準配置:
  /index.html          ← MFDCOのツール一覧
  /MFDCO_math/         ← このフォルダ
    index.html
    calculator.html
    ...

公開版ではボタンのリンク先を https://mfdco.net/tools.html に固定しています。

リンク先を変更する場合:
mfdco-shell.js の先頭付近にある

  const MFDCO_TOOLS_LIST_URL="https://mfdco.net/tools.html";

だけを変更してください。


Chrome / 短い画面
-------------------
Chromeのブックマークバー等で利用可能な縦幅が小さい場合も、計算コード下の実行ボタンが隠れないよう、右カラムは自動的に縮小・内部スクロールします。
