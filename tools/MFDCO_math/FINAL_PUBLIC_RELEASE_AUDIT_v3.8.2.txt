STATUS

PUBLIC RELEASE CANDIDATE: PASS

Blocking defects found and fixed
--------------------------------
1. Results-page graph area could collapse almost to zero height.
   The page had 4 major sections but CSS only allocated 3 explicit grid rows.
   Fixed with a 4-row, scroll-safe layout and a minimum 360px graph workspace.

2. 12 legacy one-click templates were not immediately executable.
   They depended on undefined variables such as a/b/c, v0, rho, I, R, E, etc.
   All now contain usable example input values.

3. New graph series stored "expr" while older Results UI expected "expression".
   This caused graph legends/statistics to lose the actual expression label.
   Compatibility metadata is now generated.

4. Newly sampled graphs did not include numerical statistics.
   min / max / mean / standard deviation / point count are now generated.

5. Graph-analysis selectors could become stale after Apply/Clear/card selection.
   Selection synchronization was added.
