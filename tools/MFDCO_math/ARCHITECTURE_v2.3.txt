MFDCO Tools v2.3 Architecture
================================

New in v2.3
-----------
mfdco-results.js
  Shared graph renderer, robust Y-range calculation, graph cards,
  statistics table generation and PNG canvas export.

mfdco-manifest.js
  Declares application version, project format, module versions and
  supported capabilities. Used by diagnostics.

diagnostics.html
  Browser-visible automated health check for modules, math, numerical
  analysis, interpreter, ANS, units, calendars, templates, storage and plots.

results.html
  No longer owns the graph drawing implementation. It is now mostly
  page state/editor interaction and delegates rendering to mfdco-results.js.

3. Split Wiki content data from Wiki presentation.
