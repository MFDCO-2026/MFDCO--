MFDCO_math Wiki

関数電卓・コード実行・グラフ・単位変換・暦変換・ファイル管理をまとめた総合マニュアルです。

初めて使う場合は「5分クイックスタート」から、構文を調べたい場合は左上の検索欄から関数名を入力してください。

まず使ってみる コードを書く グラフを描く 関数を探す エラーを直す

1. はじめに

MFDCO_math は、通常の関数電卓としての操作と、複数行の計算コードを使う操作を同じ計算環境で扱うツールです。簡単な計算は関数電卓、変数や繰り返し処理を含む計算はコード画面、グラフ確認は結果画面、単位は単位変換器を使います。

初級

四則演算、三角関数、ANS、単位変換、テンプレートを使う。

中級

変数、複数行コード、if / for、工学関数、plot() を使う。

上級

数値微積分、求根、while、複数グラフ、複雑な工学式を組み合わせる。

5分クイックスタート

関数電卓で式を入力→= で計算→答えを保存→コードへ追加→必要なら plot()→結果画面で確認
# まずはコード画面で実行
a = 3
b = 4
c = sqrt(a^2 + b^2)
print("斜辺", c)
result = c
ポイント: べき乗は ^ を使えます。例: x^2。コード画面は Ctrl + Enter でも実行できます。

2. 関数電卓

画面左側が通常の関数電卓です。ボタン操作でもキーボード入力でも式を作れます。= を押すと計算し、次の入力を始めるまでは式と答えが残ります。

式を追加

現在の式をコードエディタへ追加します。コードで選択していた位置がある場合はその位置に挿入します。

答えを追加

計算結果の数値だけをコードへ追加します。

答えを保存

答えを ANS(n) として履歴へ保存します。

DEG / RAD

三角関数の角度モードを切り替えます。DEGは度、RADはラジアンです。

％ と ±: % は百分率として扱います（例: 200*10% → 20）。余りは mod を使います。± は現在の式全体の符号を反転します。

入力例

sqrt(3^2 + 4^2)
sin(30)
log10(1000)
nCr(10, 3)

3. 変数・ANS

変数

変数は「名前 = 値」の形で使います。コード画面では代入した変数を、その後の行から何度でも利用できます。

mass = 12.5
velocity = 30
energy = kineticEnergy(mass, velocity)
print("運動エネルギー", energy)

変数名は英字または _ から始め、後ろに数字を付けられます。例: v1, rho_water2, project_mass。

ANS履歴

関数電卓で「答えを保存」を押すと ANS(1), ANS(2) …として参照できます。

a = ANS(1)
b = ANS(2)
result = a + b
ANS番号は保存履歴に対応します。プロジェクト保存時にはANS履歴も一緒に保存されます。

4. コード画面

左約1/4が候補、右側が大きなコードエディタと結果/ログです。候補をクリックすると、最後に選択したコード位置へ挿入されます。

角度モード: コード画面にも DEG / RAD 切替があります。関数電卓と同じ設定を共有し、プロジェクト保存にも含まれます。

基本構文

代入
x = 10
y = x * 2
出力
print("x =", x)

print() の内容は結果 / ログへ表示されます。

コメント
# この行は実行されません
x = 10  # 行末コメント
result
result = sqrt(2)

result に代入すると、その値を明示的な主要結果としてログに出せます。

制御構文

if / else

x = 12
if x > 10:
  print("10より大きい")
else:
  print("10以下")

for

for i = 1 to 5:
  print(i)

while

x = 0
while x < 5:
  x = x + 1
  print(x)

比較・論理演算子

分類構文意味
比較== != < > <= >=等しい、等しくない、大小比較
論理AND条件1 and 条件2両方が真
論理OR条件1 or 条件2どちらかが真
否定not 条件真偽を反転
インデント: if / for / while の中は現在2スペースで字下げするのが安全です。無限ループ防止のため while には反復上限があります。

5. グラフ

plot() はコードを実行した画面には直接描画せず、グラフデータを「結果」ページへ送ります。

基本構文

plot(x, y式, xmin, xmax)

第1引数がX軸変数、最後の2引数がX軸範囲、その間がY式です。

1系列

plot(x, x^2 - 4*x + 3, -2, 6)

複数系列

plot(x, sin(x), cos(x), tan(x), -180, 180)

1つの plot() に最大8系列まで指定できます。また、複数の plot() を実行すれば、結果画面では別々のグラフとして自動分割されます。

グラフ編集では、タイトル、X/Y軸ラベル、X範囲、グリッド表示を変更でき、各グラフをPNG保存できます。

6. 結果画面

結果ページは上から「結果 / ログ」「グラフ＋数値特性」「グラフ編集」の3段構成です。

結果 / ログ

print()、result、エラー、plot実行通知などを表示。

数値特性

系列ごとの min / max / 平均 / 標準偏差 / 有効点数を表で確認。

画像出力

各グラフのPNGボタン、または編集欄の出力ボタンから保存。

7. 単位変換

変換元を選ぶと、その単位と同じ種類だけが「変換先」候補に表示されます。SI接頭語は単位とは別の欄で指定します。

対応例

SI・工学

m, kg, s, N, Pa, J, W, Hz, Ω, V, A, F, H, Wb, T など。

尺貫法・英米

寸、尺、間、丈、里、坪、合、升、匁、斤、貫、inch、ft、mile、gallon 等。

特殊

光年、AU、pc、TNT換算、放射線、粘度、Minecraft単位など。

ユーザー定義単位

「1個の独自単位が基準単位の何倍か」を保存できます。

例:
単位名 = MFDCO距離
記号 = md
種類 = 長さ
基準単位 = m
倍率 = 2.5

→ 1 md = 2.5 m

保存した単位は、その後の通常の変換候補と単位一覧にも追加されます。

8. 暦・日付変換

西暦、皇紀、元号、Julian Day Numberから日付を入力し、複数の暦情報へ変換できます。

日付情報

曜日、ISO週、年内通算日、Julian Day、MJD。

日本

皇紀、日本元号。元号候補は大化から令和まで。

他暦

ユリウス暦、仏暦、民国紀元、イスラム暦、ヘブライ暦、ペルシャ暦、インド国定暦、中国暦。

歴史上の日付

古代・中世は当時の暦法と現代西暦の対応が単純ではないため、歴史用途では参考換算として扱います。

12. 上級テクニック

工学計算を段階化する

rho = 1.225
v = 80
Cd = 0.32
A = 2.1

q = dynamicPressure(rho, v)
Fd = dragForce(rho, v, Cd, A)

print("動圧", q)
print("抗力", Fd)

数値解とグラフを組み合わせる

root = solve("x^3 - 4*x - 1", "x", 0, 3)
print("root", root)
plot(x, x^3 - 4*x - 1, -3, 3)

複数ケースを for で試す

for v = 10 to 100:
  q = dynamicPressure(1.225, v)
  if q > 2000:
    print("2000 Paを超える速度", v)
同じ計算を何度も手入力するより、変数化・関数化された組み込み式・ループを組み合わせるとミスが減ります。

13. エラー対処

システム診断: 更新後の関数・単位・暦・plot・保存・モジュール接続は 診断ページ から一括確認できます。
症状確認すること
ERROR (line N)N行目の構文・変数名・括弧・引数個数を確認。
変数が未定義使う前の行で x = ... と代入したか確認。
計算できない平方根の負数、0除算、対数の0以下など数学的な定義域を確認。
solve が失敗指定区間の両端で式の符号が変わる区間を与える。
plot() が表示されないコード実行後、ヘッダーの「結果」を開く。X範囲や式も確認。
if / for / while が不自然末尾の : と、内部の2スペースインデントを確認。
単位変換先が出ない変換元と同じ種類の単位だけが候補になります。
読み込んだプロジェクトがおかしいMFDCO専用プロジェクト形式か確認し、必要なら元ファイルを再エクスポート。
