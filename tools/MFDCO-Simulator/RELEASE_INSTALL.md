# MFDCO 戦闘シミュレーター v1.3 — 設置・更新

## 公開方法
1. 公開用ZIPを展開します。
2. `index.html` と同じ場所にあるファイル・`data/` を、階層を変えずに公開先のフォルダーへ全てアップロードします。
3. ツール一覧から、そのフォルダーの `index.html` にリンクします。
4. HTTPSで開き、新規作品、地図テンプレート読込、保存、再読込を確認します。

外部データベース、APIキー、サーバー側プログラム、npmのビルド作業は不要です。
`.mjs` を JavaScript のMIMEタイプ（text/javascript または application/javascript）で配信してください。
JSON・SVG・CSSも通常の静的ファイルとして配信します。サブフォルダー配置に対応します。
ファイルを直接ダブルクリックする `file://` ではモジュールや地図データが読み込めません。

推奨はデスクトップ版Chrome/Edgeと、1280×720以上の表示領域です。
WebM出力はブラウザーのWebCodecs対応が必要です。使えない場合はPNG連番を選択してください。
動画出力とプロジェクト保存はブラウザーで処理し、入力した作品を外部サーバーへ送信しません。
フィードバック・ツール一覧・資料リンクは外部ページを開きます。

## 更新時
- 更新前に、編集中のプロジェクトと必要な固定リプレイをファイル保存してください。
- 公開先の全ファイルをまとめて更新してください。旧JSと新JSの混在を避けます。
- HTML・JS・CSSは長期間固定キャッシュにせず、更新後は再読み込みしてください。
- 同じURL・同じブラウザーなら端末保存を引き継ぎます。別ドメイン・別ブラウザーへはプロジェクトファイルで移します。
- 自動保存、復元ポイント、保存した地図テンプレートはlocalStorage / IndexedDBを使用します。ブラウザーのデータ削除で消えるため、ダウンロード保存も併用してください。

## 現在の対応範囲
- 作中時間は1frameあたり1〜600秒。計算は1秒刻みの決定的処理です。
- 計算エンジン・保存形式は0.31.0を維持。アプリ公開版番号は1.3.0です。
- 地図制作、戦況編集、武器管制、作戦概要、CIC等の演出画面と映像出力を利用できます。
- 共有はプロジェクト・地図ファイルの配布方式です。オンライン投稿一覧・アカウント管理はありません。
- 戦闘は作品制作向けの抽象モデル。実兵器の性能、迎撃率、正確な戦史を保証するものではありません。
- 地域参考図の市街・設備配置は簡略化した参考配置です。出典情報は地図データ内に保持します。
- 自動迂回、実路線上の配送車両、魚雷・電子戦等の専用挙動、全地域の詳細な史実配置は今後の拡張です。
- 高解像度地図や大量配置は端末性能に影響します。横128セルを基準に、必要な範囲だけ増やしてください。

## 公開先での最終確認（数分）
- 地図編集上部に「現在の地形・標高を置換」が見えること。
- テンプレートを読み込めること。地形を編集し、Undoで戻せること。
- プロジェクトを保存し、再読込して同じ配置になること。
- 再生、シーク、武器管制の表示切替が動くこと。
- PNG保存、短いPNG連番、対応環境ではWebMを書き出せること。
- ウィンドウサイズ・ズーム率を変えて、ヘッダーや右端が欠けないこと。

本リリースは自動テストとDOM操作検証を実施しています。実Chromeの描画・動画コーデック・公開先固有の設定は、公開先で上記を確認してください。
